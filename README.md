# Генератор браузерных игр по промпту

MVP кейса Билайна «Вайбкодинг игр»: пользователь пишет запрос на естественном языке,
LLM генерирует самодостаточную HTML5-игру (Canvas + JS), игра сразу запускается в предпросмотре.

## Запуск

Требуется Node.js 22+ и ключ Anthropic API (получить: https://console.anthropic.com → API Keys, нужен баланс на счёте).

```bash
npm install
cp .env.example .env        # впишите ключ: ANTHROPIC_API_KEY=sk-ant-...
npm start                   # http://localhost:3000
npm test                    # юнит-тесты и тесты сервера
npm run e2e                 # сквозная проверка в Chromium с подменой LLM (нужен Chromium, CHROMIUM_PATH)
```

Ключ хранится только на сервере (файл `.env` в git не попадает), в браузер не передаётся.
Модель по умолчанию `claude-sonnet-5-5`, меняется переменной `ANTHROPIC_MODEL`.
Адрес API можно сменить через `ANTHROPIC_BASE_URL` (прокси, совместимый шлюз).

## Архитектура

```
Браузер (public/)                    Сервер (server.js)                 LLM
 промпт + аудитория  ── POST ──▶  /api/generate                 ──▶  Messages API
                                    lib/generate.js:
                                     - системный промпт
                                     - извлечение ```html
                                     - проверка: canvas, без внешних ресурсов и сети
 iframe sandbox="allow-scripts" ◀── { html } ◀──
 доработка: previous + change  ──▶  тот же эндпоинт
```

- `lib/generate.js` — сборка промпта, разбор ответа, валидация игры, вызов LLM.
- `server.js` — HTTP-сервер без зависимостей: статика и `POST /api/generate`.
- `public/` — форма ввода, предпросмотр в песочнице, доработка, скачивание HTML.
- `test/` — тесты через `node:test`. Вызов LLM подменяется в тестах, реальный API не нужен.

## Соответствие требованиям кейса

| Требование | Статус |
| --- | --- |
| Текстовый ввод промпта | Сделано: `public/index.html` |
| Генерация через LLM, без шаблона | Сделано: `lib/generate.js` |
| Playable-результат (старт, геймплей, победа/поражение) | Задано системным промптом, нужна проверка на реальных генерациях |
| WebView-совместимость (self-contained) | Сделано: валидация запрещает внешние ресурсы и сеть |
| Команда 2–4 человека, git-история | Репозиторий есть, состав команды указать |
| Презентация 3–5 минут | Не сделано (план демо ниже) |
| LLM в пайплайне | Сделано: Anthropic Messages API |
| Адаптация под аудиторию | Сделано: дети / взрослые / пожилые |
| Итеративная доработка | Сделано: поле «Что доработать» |
| Галерея и аналитика игр | Не сделано |
| Генерация ассетов (графика, звук) | Не сделано |
| Touch-управление | Требуется системным промптом, проверить в генерациях |

## План демо для презентации

1. Промпт «замути змейку для бабушки», аудитория «пожилые».
2. Игра открывается в предпросмотре, показываем крупный UI.
3. Доработка «сделай кнопки больше», игра обновляется.
4. Схема архитектуры из раздела выше.

## Окружение разработки

- Node.js 22, npm 9.
- `playwright` (devDependency) для браузерных проверок. Для запуска используется системный Chromium
  (`/snap/bin/chromium`), так как Playwright не скачивает браузер для этой версии Ubuntu.
