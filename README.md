# GameForge — ИИ-генератор браузерных игр по промпту

MVP для кейса Билайна «Вайбкодинг игр». Пользователь пишет запрос на обычном языке
(«замути змейку для бабушки»), LLM пишет самодостаточную HTML5-игру (Canvas + JS),
и она сразу запускается в окне, имитирующем WebView на телефоне.

Демо-видео: [docs/demo.mp4](docs/demo.mp4) (ответ LLM в нём симулирован).

## Стек

| Часть | Технология |
| --- | --- |
| Интерфейс | React 19 + Vite |
| Сервер | Node.js 22, без фреймворков (`server.js`) |
| LLM | Anthropic Messages API, модель `claude-sonnet-5-5` |
| Сгенерированная игра | один HTML-файл: HTML5 Canvas и чистый JS, без внешних зависимостей |
| Тесты | `node:test`, Playwright для сквозной проверки |

Ключ API хранится только на сервере и в браузер не попадает.

## Что нужно установить

1. **Node.js 22 или новее** — https://nodejs.org (скачайте LTS). Проверка: `node -v`.
2. **Git** — https://git-scm.com. Проверка: `git --version`.
3. **Ключ Anthropic API** (получение ниже).

## Как получить ключ

1. Откройте https://console.anthropic.com и войдите или зарегистрируйтесь.
2. Раздел **Billing**: пополните баланс (без него API не отвечает).
3. Раздел **API Keys** → **Create Key**, скопируйте ключ вида `sk-ant-...`. Он показывается один раз.

## Установка и запуск

```bash
git clone <адрес-репозитория>
cd <папка-проекта>
npm install
```

### Куда вписать ключ

В корне проекта создайте файл **`.env`** (копия шаблона `.env.example`) и впишите ключ:

```bash
cp .env.example .env          # Windows (cmd):  copy .env.example .env
```

Откройте `.env` и после знака равно вставьте ключ:

```
ANTHROPIC_API_KEY=sk-ant-ваш-ключ
```

Файл `.env` добавлен в `.gitignore`, в репозиторий он не попадёт. Никому не показывайте ключ.

### Запуск

```bash
npm start
```

Команда соберёт интерфейс и запустит сервер. Откройте http://localhost:3000.

1. Введите запрос или выберите пример.
2. Выберите аудиторию (дети, взрослые, пожилые).
3. Нажмите «Создать игру», ожидание до минуты.
4. Играйте в окне телефона. Для правок напишите «сделай кнопки больше» или нажмите готовую подсказку.
5. Игры сохраняются в блоке «Мои игры» (в браузере). Любую игру можно скачать одним HTML-файлом.

### Режим разработки (интерфейс с горячей перезагрузкой)

Нужны два терминала:

```bash
npm run server     # терминал 1: сервер API на :3000
npm run dev        # терминал 2: интерфейс на http://localhost:5173
```

## Расход токенов

Токены тратит только реальная генерация. `npm test`, `npm run e2e` и `npm run demo:record` идут через подмену LLM и бесплатны.
Как сократить расход на тестах (переменные в `.env`):

| Что сделать | Как |
| --- | --- |
| Более дешёвая модель | `ANTHROPIC_MODEL=claude-haiku-5-5`, для финальной демонстрации вернуть `claude-sonnet-5-5` |
| Ниже потолок ответа | `MAX_TOKENS=8000` (по умолчанию 16000) |
| Без повторного запроса | `MAX_ATTEMPTS=1` (по умолчанию 2, при невалидной игре запрос повторяется) |
| Интерфейс без модели | `npm run demo:llm`, см. ниже |

Системный промпт уже просит компактный код (до 250 строк). Каждая доработка отправляет модели игру целиком, поэтому несколько правок лучше писать одним запросом.

## Проверка и демо

```bash
npm test             # юнит-тесты и тесты сервера (без ключа и сети)
npm run e2e          # сквозная проверка в Chromium с подменой LLM
npm run demo:llm     # симуляция LLM на :4010 для запуска без ключа
npm run demo:record  # перезаписать видео (нужны Chromium и ffmpeg)
```

Запуск без ключа с симуляцией LLM (покажет интерфейс, но игра всегда «змейка»):

```bash
npm run demo:llm
# в другом терминале:
ANTHROPIC_API_KEY=x ANTHROPIC_BASE_URL=http://localhost:4010 npm run server
```

Для `e2e` и `demo:record` путь к Chromium задаётся переменной `CHROMIUM_PATH` (по умолчанию `/snap/bin/chromium`).

## Если что-то не работает

| Симптом | Причина и решение |
| --- | --- |
| «Не задан ключ API» | Нет файла `.env` или в нём пустой `ANTHROPIC_API_KEY`. Заполните и перезапустите сервер |
| «Ключ API не подошёл» | Ключ скопирован с ошибкой или отозван. Создайте новый |
| Ошибка 429 | Превышен лимит запросов, подождите минуту |
| Ошибка 402/403 от LLM | Нет баланса на аккаунте Anthropic |
| «Фронтенд не собран» | Запускайте через `npm start` или выполните `npm run build` |
| Порт 3000 занят | Задайте другой в `.env`: `PORT=3100` |
| Игра не запускается | Нажмите «Доработать» с текстом «исправь ошибки», либо создайте игру заново |

## Архитектура

```
Браузер (React, src/)                Сервер (server.js)               LLM
 промпт + аудитория ──── POST ───▶  /api/generate            ───▶  Messages API
                                      lib/generate.js:
                                       системный промпт + аудитория
                                       извлечение ```html
                                       проверка: canvas, нет внешних ресурсов и сети
                                       повтор запроса, если игра не прошла проверку
 iframe sandbox="allow-scripts" ◀── { html } ◀──
 доработка: previous + change ───▶  тот же эндпоинт
```

- `src/` — интерфейс: форма, предпросмотр в рамке телефона, доработка, галерея (localStorage).
- `lib/generate.js` — сборка промпта, вызов LLM, разбор и проверка ответа.
- `server.js` — отдаёт собранный интерфейс из `dist/` и `POST /api/generate`.
- `demo/` — симуляция LLM и скрипт записи видео. В самом генераторе заготовок игр нет.
- `test/` — тесты.

| Требование | Статус |

| Git-репозиторий с историей | Сделано |
| Презентация 3–5 минут | Не сделана. Сценарий демо ниже |
| LLM в пайплайне | Сделано |
| Адаптация под аудиторию | Сделано |
| Итеративная доработка | Сделано |
| История и галерея игр | Сделано (в браузере, без «поделиться») |
| Touch-управление, адаптивность | Требуется системным промптом, интерфейс адаптивен |

## Сценарий демо (3–5 минут)

1. Промпт «замути змейку для бабушки», аудитория «Пожилые».
2. Игра появляется в окне телефона, показываем крупный интерфейс.
3. Доработка «сделай кнопки больше».
4. Схема архитектуры из раздела выше.
5. Второй жанр для сравнения: «яркий кликер для детей».
