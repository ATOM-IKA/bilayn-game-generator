# GameForge — ИИ-генератор браузерных игр по промпту

MVP для кейса Билайна «Вайбкодинг игр». Пользователь пишет запрос на обычном языке
(«замути змейку для бабушки»), LLM пишет самодостаточную HTML5-игру (Canvas + JS),
и она сразу запускается в окне, имитирующем WebView на телефоне.

Демо-видео: [docs/demo.mp4](docs/demo.mp4) (ответ LLM в нём симулирован).

## Стек

| Часть | Технология |
| --- | --- |
| Интерфейс | React 19 + Vite |
| Сервер | Node.js 22, без фреймворков (`server.js`) |
| LLM | OpenAI (по умолчанию, `gpt-5`) или Anthropic Claude, выбор в `.env` |
| Сгенерированная игра | один HTML-файл: HTML5 Canvas и чистый JS, без внешних зависимостей |
| Тесты | `node:test`, Playwright для сквозной проверки |

Ключ API хранится только на сервере и в браузер не попадает.

## Что нужно установить

1. **Node.js 22 или новее** — https://nodejs.org (скачайте LTS). Проверка: `node -v`.
2. **Git** — https://git-scm.com. Проверка: `git --version`.
3. **Ключ OpenAI API** (получение ниже). Вместо него можно использовать ключ Anthropic.

## Как получить ключ

**OpenAI (основной вариант):**
1. Откройте https://platform.openai.com и войдите или зарегистрируйтесь.
2. Раздел **Billing**: пополните баланс (без него API не отвечает).
3. Раздел **API keys** → **Create new secret key**, скопируйте ключ вида `sk-...`. Он показывается один раз.

**Anthropic (запасной вариант):** https://console.anthropic.com → Billing → API Keys → Create Key, ключ вида `sk-ant-...`.
Чтобы использовать его, задайте в `.env` `LLM_PROVIDER=anthropic` и `ANTHROPIC_API_KEY=...`.

## Установка и запуск

```bash
git clone <адрес-репозитория>
cd <папка-проекта>
npm install
```

### Куда вписать ключ

В корне проекта создайте файл **`.env`** (копия шаблона `.env.example`) и впишите ключ:

```bash
cp .env.example .env          # Windows (cmd):  copy .env.example .env
```

Откройте `.env` и после знака равно вставьте ключ:

```
LLM_PROVIDER=openai
OPENAI_API_KEY=sk-ваш-ключ
```

Имя переменной пишется точно, с подчёркиванием (`OPENAI_API_KEY`), без пробелов и кавычек вокруг ключа.
После любого изменения `.env` перезапустите сервер. Остальные настройки и их значения по умолчанию описаны в `.env.example`.

Файл `.env` добавлен в `.gitignore`, в репозиторий он не попадёт. Никому не показывайте ключ.

### Запуск

```bash
npm start
```

Команда соберёт интерфейс и запустит сервер. Откройте http://localhost:3000.

1. Введите запрос или выберите пример.
2. Выберите аудиторию (дети, взрослые, пожилые).
3. Нажмите «Создать игру», ожидание до минуты.
4. Играйте в окне телефона. Для правок напишите «сделай кнопки больше» или нажмите готовую подсказку.
5. Игры сохраняются в блоке «Мои игры» (в браузере). Любую игру можно скачать одним HTML-файлом.

### Режим разработки (интерфейс с горячей перезагрузкой)

Нужны два терминала:

```bash
npm run server     # терминал 1: сервер API на :3000
npm run dev        # терминал 2: интерфейс на http://localhost:5173
```

## Лимит и расход токенов

- **Потолок на одну генерацию: 5 000 000 токенов** (`GENERATION_TOKEN_LIMIT`, по умолчанию именно столько). Считаются входные и выходные токены по данным API, по всем попыткам одной генерации вместе. Практически это значит, что на игру можно тратить сколько нужно.
- **Потолок одного ответа** `MAX_TOKENS`: для `gpt-5` и o-серии по умолчанию 128 000 (максимум этих моделей, в него входят и токены рассуждений), для остальных моделей 16 000. Запросить в одном ответе миллионы токенов нельзя: API отклонит такой запрос, поэтому 5 млн это потолок именно на всю генерацию, а не на один ответ.
- **Общий лимит** `TOKEN_BUDGET` по умолчанию выключен. Если задать, генерация остановится, когда суммарный расход дойдёт до него. Расход хранится в файле `.usage.json`, переживает перезапуск и виден в шапке интерфейса. Начать счёт заново можно, удалив этот файл.
- **Качество против цены.** По умолчанию до 3 попыток на игру: если игра не прошла проверку (в том числе на синтаксис JavaScript), модели отправляется список проблем, и она исправляет код. Каждая попытка расходует токены. Для дешёвых прогонов: `OPENAI_REASONING_EFFORT=low`, `MAX_ATTEMPTS=1`, более лёгкая модель в `OPENAI_MODEL`.
- `npm test`, `npm run e2e` и `npm run demo:record` идут через подмену LLM и токены не тратят.
- Каждая доработка отправляет модели игру целиком, поэтому несколько правок лучше писать одним запросом.

## Качество игр

Системный промпт в `lib/generate.js` задаёт стандарт: экран старта, игровой цикл с учётом времени кадра, победа и поражение, рекорд, пауза при потере фокуса,
управление клавиатурой и касаниями, адаптивный Canvas, анимации и частицы, звук через Web Audio, подсказки по механике для разных жанров и аудиторий.
Перед показом игра проходит проверку: есть Canvas, цикл и ввод, нет внешних ресурсов и сетевых вызовов, **скрипт без синтаксических ошибок**.
Если проверка не пройдена, ответ автоматически уточняется.

## Проверка и демо

```bash
npm test             # юнит-тесты и тесты сервера (без ключа и сети)
npm run e2e          # сквозная проверка в Chromium с подменой LLM
npm run demo:llm     # симуляция LLM на :4010 для запуска без ключа
npm run demo:record  # перезаписать видео (нужны Chromium и ffmpeg)
```

Запуск без ключа с симуляцией LLM (покажет интерфейс, но игра всегда «змейка»):

```bash
npm run demo:llm
# в другом терминале:
LLM_PROVIDER=openai OPENAI_API_KEY=x OPENAI_BASE_URL=http://localhost:4010 npm run server
```

Для `e2e` и `demo:record` путь к Chromium задаётся переменной `CHROMIUM_PATH` (по умолчанию `/snap/bin/chromium`).

## Если что-то не работает

| Симптом | Причина и решение |
| --- | --- |
| «Не задан ключ API» | Нет файла `.env` или в нём пустой `OPENAI_API_KEY` (проверьте, что имя написано с подчёркиванием). Заполните и перезапустите сервер |
| «Ключ API не подошёл» | Ключ скопирован с ошибкой, отозван или относится к другому сервису. Создайте новый |
| «Лимит запросов или недостаточно средств» | Пополните баланс OpenAI или подождите минуту |
| «Модель не найдена» | Укажите доступную вам модель в `OPENAI_MODEL` |
| «Игра получилась слишком большой» | Увеличьте `MAX_TOKENS` (у моделей с рассуждением часть токенов уходит на «размышления») |
| «Достигнут общий лимит токенов» | Расход дошёл до `TOKEN_BUDGET`. Удалите `.usage.json` или увеличьте лимит |
| «Генерация превысила потолок токенов» | Одна генерация израсходовала `GENERATION_TOKEN_LIMIT`. Упростите запрос или увеличьте потолок |
| «Отказано в доступе» при `npm start` | Проект запущен из архива или с носителя без права запуска. Распакуйте в обычную папку и выполните `npm install` |
| «Фронтенд не собран» | Запускайте через `npm start` или выполните `npm run build` |
| Порт 3000 занят | Задайте другой в `.env`: `PORT=3100` |
| Игра не запускается | Нажмите «Доработать» с текстом «исправь ошибки», либо создайте игру заново |

## Архитектура

```
Браузер (React, src/)                Сервер (server.js)               LLM
 промпт + аудитория ──── POST ───▶  /api/generate            ───▶  Chat Completions / Messages API
                                      lib/generate.js:
                                       системный промпт + аудитория
                                       извлечение ```html
                                       проверка: canvas, цикл, ввод, нет сети, JS без ошибок
                                       повтор с описанием проблем, если проверка не пройдена
                                       учёт токенов (lib/budget.js), потолок 5 000 000 на генерацию
 iframe sandbox="allow-scripts" ◀── { html } ◀──
 доработка: previous + change ───▶  тот же эндпоинт
```

- `src/` — интерфейс: форма, предпросмотр в рамке телефона, доработка, галерея (localStorage).
- `lib/generate.js` — системный промпт, вызов LLM, разбор и проверка ответа.
- `lib/providers.js` — адаптеры OpenAI и Anthropic. `lib/budget.js` — лимит токенов.
- `server.js` — отдаёт собранный интерфейс из `dist/` и `POST /api/generate`.
- `demo/` — симуляция LLM и скрипт записи видео. В самом генераторе заготовок игр нет.
- `test/` — тесты.
